# Ticket 3.3 -- Implement Candidate Range Construction

**Epic:** 3 -- Entropy-Aware Scan
**Complexity:** Medium

## Goal

After successful:

- Pre-SOS parsing
- Entropy scan

Construct a validated recovery range:

```rust
struct Candidate {
    start: usize,
    end: usize,
    status: RecoveryStatus, // Recovered | Truncated
}
```

Responsibilities:

- Use:
  - `start` from SOI
  - `end` from entropy result
- Ensure:
  - `end > start`
  - Range does not exceed `max_size`
- Return structured candidate result

- [ ] Truncated candidate correctly flagged
