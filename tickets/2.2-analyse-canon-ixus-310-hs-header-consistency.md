# Ticket 2.2 — Analyse Canon IXUS 310 HS Header Consistency

**Epic:** 2 — Camera-Aware JPEG Reconstruction
**Complexity:** Medium

## Goal

Compare multiple clean JPEGs from the Canon IXUS 310 HS and identify which header segments are stable enough to form a reusable camera profile.

## Why

You need to know whether quantisation tables, Huffman tables, restart interval, and component layout are consistent across reference photos.

## Scope

Using the output of Ticket 2.1, inspect 5–10 clean reference JPEGs and compare:

- marker ordering
- number of DQT segments
- quantisation table contents
- number of DHT segments
- Huffman table contents
- SOF0 component count and sampling factors
- DRI presence and value
- SOS component mapping

Document which fields are:

- invariant
- resolution-dependent
- metadata-only / ignorable

## Deliverables

- Short technical note summarising stable vs variable fields
- Decision on whether one reusable header template is sufficient
- Sample Canon IXUS 310 HS profile specification

## Acceptance Criteria

- [ ] Comparison is done across multiple reference JPEGs
- [ ] Clear conclusion on which fields belong in the camera profile
- [ ] Resolution-dependent fields are explicitly identified
