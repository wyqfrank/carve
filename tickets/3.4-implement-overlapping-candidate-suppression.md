# Ticket 3.4 -- Implement Overlapping Candidate Suppression

**Epic:** 3 -- Entropy-Aware Scan
**Complexity:** Medium

## Goal

When multiple validated candidates overlap in byte range, suppress duplicates deterministically.

## Problem

Multiple `FF D8` markers may exist inside the same JPEG container, producing overlapping candidates.

Example:

```text
SOI A --------- EOI
     SOI B ---- EOI
```

Both structurally valid, but represent the same image.

## Responsibilities

Given:

- `Vec<Candidate>`

Implement suppression:

- Sort by:
  - `start` ascending
  - `end` ascending
- Iterate in order.
- Emit candidate only if:
  - `candidate.start >= last_emitted_end`

Suppress:

- Fully nested candidates
- Partially overlapping candidates

Edge Cases:

- Identical start/end -> emit only one
- Complete vs truncated overlap -> complete wins

## Definition of Done

- [x] Nested SOIs suppressed
- [x] Non-overlapping JPEGs still emitted
- [x] Behavior deterministic
- [x] No change to parsing logic
