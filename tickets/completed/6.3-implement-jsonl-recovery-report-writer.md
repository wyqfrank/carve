# Ticket 6.3 -- Implement JSONL Recovery Report Writer

**Epic:** 6 -- Reporting Upgrade
**Complexity:** Low

## Goal

Write one JSON object per recovered candidate to a JSONL output file.

## Suggested Shape

```rust
fn write_report(
    path: &Path,
    candidates: &[Candidate]
) -> Result<(), ReportError>
```

## Responsibilities

- Write one line per candidate
- Preserve deterministic ordering
- Include metadata and recovery status

## Definition of Done

- [x] JSONL file written successfully
- [x] One line per candidate
- [x] Output readable by external tools

## Implementation

Added to `report.rs`:
- `ReportError(io::Error)` — wraps IO errors with `Display` and `From<io::Error>`
- `write_report(path: &Path, candidates: &[ValidatedCandidate]) -> Result<(), ReportError>` — creates file, writes one `JsonlRecord::to_json_line()` per candidate with a trailing newline, buffered
- Three unit tests covering multi-candidate output, empty input, and JSON field content
