# Ticket 2.9 — Benchmark Phase 2 Against Phase 1

**Epic:** 2 — Camera-Aware JPEG Reconstruction
**Complexity:** Low

## Goal

Evaluate whether camera-aware reconstruction materially improves recovery quality compared with raw carved outputs.

## Why

You need evidence that Phase 2 actually works.

## Scope

Select a small benchmark set of corrupted photos and compare:

- Phase 1 raw carve
- Phase 2 camera-header rebuild
- Phase 2 camera-header + offset search

Track for each sample:

- decodes or not
- major artefacts present
- colour correctness
- visual quality ranking

## Deliverables

- Benchmark note or markdown table
- Before/after image set
- Summary of success rate and common remaining failures

## Acceptance Criteria

- [x] Benchmark uses multiple real examples
- [x] Results clearly show whether Phase 2 improves outputs
- [x] Remaining failure modes are documented for next phase

## Implementation

- `crates/carve-core/tests/benchmark_phase_comparison.rs` — automated benchmark test over all clean fixtures
- `docs/benchmark-phase2.md` — full results table, interpretation, and failure mode analysis
- Run with: `cargo test -p carve-core benchmark_phase -- --nocapture`
