# Ticket 3.6 -- Implement Candidate Scanner to Validator Flow

**Epic:** 3 -- Entropy-Aware Scan
**Complexity:** Medium

## Goal

Connect SOI scanning to candidate validation.

Given a byte stream:

1. Find all SOI offsets
2. Validate each candidate
3. Collect successful candidate results

## Suggested Shape

```rust
fn recover_candidates(
    bytes: &[u8],
    options: &RecoveryOptions
) -> Vec<Candidate>
```

## Responsibilities

- Scan for SOI offsets
- Iterate candidate starts
- Call `validate_candidate(...)`
- Collect successful results
- Ignore invalid candidates cleanly

## Definition of Done

- [x] All SOI candidates are attempted
- [x] Invalid candidates do not panic
- [x] Successful candidates are collected deterministically
