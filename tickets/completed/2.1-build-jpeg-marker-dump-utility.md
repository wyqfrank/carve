# Ticket 2.1 — Build JPEG Marker Dump Utility

**Epic:** 2 — Camera-Aware JPEG Reconstruction
**Complexity:** Medium

## Goal

Create a utility that parses a clean JPEG and prints / serialises its segment structure so we can inspect Canon IXUS 310 HS reference files.

## Why

Before building a camera profile, you need to verify which segments are stable across clean photos from the same camera.

## Scope

In a new module, for example `src/jpeg/marker_dump.rs`, implement logic to parse JPEG marker segments from SOI until SOS, including:

- APP0
- APP1
- DQT
- SOF0
- DHT
- DRI
- SOS

For each segment, capture:

- marker type
- file offset
- payload length
- raw payload bytes

## Deliverables

- Function to parse JPEG header segments from a file
- CLI/debug output showing ordered segment list
- Ability to dump parsed segments to JSON or debug text

## Acceptance Criteria

- [ ] Given a clean Canon IXUS 310 HS JPEG, utility prints marker order and lengths
- [ ] Output clearly distinguishes DQT, DHT, SOF0, DRI, and SOS
- [ ] Stops parsing at SOS and does not try to interpret entropy data as standard segments
