# Ticket 2.1 -- Implement Segment Length Parsing

**Epic:** 2 -- Pre-SOS Segment Parser
**Complexity:** Medium

## Goal

In `parse.rs`:

```rust
fn parse_segment(
    bytes: &[u8],
    offset: usize
) -> Result<ParsedSegment, ParseError>
```

## Responsibilities

- Validate marker prefix
- Skip fill bytes (FF FF FF)
- Read length (if applicable)
- Validate bounds

## Edge Cases

- Length < 2
- Length overflows file
- Unknown marker with valid length (must still accept)

## Definition of Done

- [ ] Reject invalid lengths
- [ ] Accept valid APP/DQT/DHT segments
