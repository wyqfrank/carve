# Ticket 6.5 -- Implement CLI Recovery Command Wiring

**Epic:** 6 -- Reporting Upgrade
**Complexity:** Medium

## Goal

Connect the full recovery pipeline to the CLI.

## Responsibilities

- Read input bytes
- Build recovery options from CLI flags
- Run candidate scanner / validator flow
- Suppress overlaps
- Write recovered JPEGs
- Write JSONL report

## Definition of Done

- [x] CLI can process a real input file end-to-end
- [x] Recovered files written
- [x] JSONL report written
- [x] No panics on malformed input

## Implementation

`main.rs` rewritten to wire the full pipeline:

1. `fs::read()` — read input bytes
2. `recover_candidates()` — scanner + validator with `allow_truncated=true`, `PatchEoiPolicy::Append`
3. `apply_validated_overlap_policy()` — suppresses overlaps unless `--keep-overlaps`
4. `extract_candidates()` — writes `recovered_000.jpg`, … to `<stem>_recovered/`
5. `write_report()` — writes `<stem>_recovered/report.jsonl`

All IO errors exit with a message and code 1 (no panics). Added `output_dir_for()` helper and a unit test for it.
