# Ticket 2.11.3 — Combine Decode-Based Scoring Function

**Epic:** 2.11 — Decode-Aware JPEG Validation & Scoring
**Complexity:** Medium

## Goal

Combine decode-based metrics into a single unified score.

## Scope

Implement scoring function:

```rust
score =
    0.4 * decode_success
  + 0.2 * colour_balance
  + 0.2 * pixel_entropy
  + 0.2 * (1 - artifact_penalty)
```

Notes:

- Clamp score to [0,1]
- If decode fails → score should be near 0

## Deliverables

- `score_image(decoded: DecodeResult) -> f32`

## Acceptance Criteria

- [x] Produces meaningful ranking across candidates
- [x] Visually correct images consistently rank higher
- [x] Broken images rank lower

## Implementation

- `crates/carve-core/src/reconstruct/scorer.rs` — `DecodeAwareScore`, `score_image`, `score_decoded_image`, `score_image_metrics`
- Combined decode-aware score uses the specified weights:
  `0.4 * decode_success + 0.2 * colour_balance + 0.2 * pixel_entropy + 0.2 * block_artifact_score`
- Existing entropy-based scoring remains intact for compatibility while decode-aware scoring is added alongside it
- Tests cover failed decode handling, clamping, formula correctness, and a real decoded JPEG fixture outranking a failed decode
