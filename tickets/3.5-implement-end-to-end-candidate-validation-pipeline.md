# Ticket 3.5 -- Implement End-to-End Candidate Validation Pipeline

**Epic:** 3 -- Entropy-Aware Scan
**Complexity:** Medium

## Goal

In `validate.rs`:

Implement a single orchestration path that takes:

- raw `bytes`
- candidate `start`
- recovery options

And performs:

1. Pre-SOS parsing
2. Entropy scan
3. Candidate range construction
4. Truncation policy
5. Confidence scoring

## Suggested Shape

```rust
fn validate_candidate(
    bytes: &[u8],
    start: usize,
    options: &RecoveryOptions
) -> Result<Candidate, ValidateError>
```

## Responsibilities

- Call `parse_until_sos(...)`
- Call `scan_entropy_stream(...)`
- Construct candidate range
- Apply truncated policy
- Apply confidence scoring
- Return one final validated candidate result

## Definition of Done

- [ ] Valid JPEG candidate returns recovered result
- [ ] Truncated JPEG candidate respects recovery options
- [ ] Invalid candidate returns structured error
- [ ] No duplicate orchestration logic outside `validate.rs`
