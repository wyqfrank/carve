# Ticket 2.11.2 — Implement Decode-Based Image Metrics

**Epic:** 2.11 — Decode-Aware JPEG Validation & Scoring
**Complexity:** Medium

## Goal

Compute quality metrics from decoded pixel data.

## Why

We need measurable signals that correlate with visual correctness, not just byte entropy.

## Scope

Implement the following metrics:

### 1. Decode Success Score

- 1.0 if decode succeeds
- 0.0 if decode fails

High weight signal.

### 2. Colour Balance Metric

Detect extreme colour casts:

- compute mean per channel (R, G, B)
- penalise large imbalance (e.g. R >> G,B)

Example idea:
`score = 1 - normalised variance between channel means`

### 3. Pixel Entropy

Compute Shannon entropy over pixel values:

- flatten RGB or per-channel
- normalise to [0, 1]

### 4. Block Artifact Heuristic

Detect repeated rows:

- compare adjacent scanlines
- count identical or near-identical rows
- high repetition → penalty

## Deliverables

- `image_metrics.rs`
- functions:
  - `compute_colour_balance(...)`
  - `compute_pixel_entropy(...)`
  - `compute_block_artifact_score(...)`

## Acceptance Criteria

- Metrics produce stable numeric outputs
- Corrupted images score noticeably worse than clean ones
- No heavy performance bottlenecks
