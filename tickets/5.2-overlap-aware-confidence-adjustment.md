# Ticket 5.2 -- Overlap-Aware Confidence Adjustment

**Epic:** 5 -- Confidence Scoring
**Complexity:** Low

## Goal

When candidates overlap:

- Penalize nested candidates slightly before suppression
- Use confidence to choose best candidate in overlapping region (optional refinement)

Example rule:

- Earlier start -> higher priority
- Complete > truncated
- Larger span preferred

This ticket is optional refinement beyond 3.4.

## Definition of Done

- [ ] Overlapping cluster consistently selects strongest candidate
- [ ] Deterministic ordering maintained
- [ ] Confidence model remains bounded 0-1
