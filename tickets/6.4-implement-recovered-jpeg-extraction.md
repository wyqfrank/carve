# Ticket 6.4 -- Implement Recovered JPEG Extraction

**Epic:** 6 -- Reporting Upgrade
**Complexity:** Medium

## Goal

Write recovered candidate byte ranges out as `.jpg` files.

## Responsibilities

- Slice original byte stream using candidate start/end
- Apply optional EOI append if patching enabled
- Name outputs deterministically
- Preserve emitted ordering

## Definition of Done

- [ ] Recovered JPEG files written to output directory
- [ ] Truncated patched files include EOI when enabled
- [ ] File naming deterministic
