# Ticket 2.7 — Add Candidate Scoring Heuristic

**Epic:** 2 — Camera-Aware JPEG Reconstruction
**Complexity:** Medium

## Goal

Automatically rank reconstructed JPEG candidates so the best-looking result can be selected without manual inspection every time.

## Why

Entropy offset search may generate many decodeable outputs; you need a simple way to prioritise likely-good recoveries.

## Scope

Implement a basic scoring heuristic using one or more of:

- successful decode status
- image dimensions matched
- absence of extreme clipping
- lower proportion of repeated rows/blocks
- reasonable colour distribution
- entropy of pixel values

This does not need to be perfect. It just needs to separate obviously broken candidates from plausible ones.

## Deliverables

- Candidate scoring function
- Ranked output list
- Optional score in filename or sidecar metadata

## Acceptance Criteria

- [ ] Candidates receive a numeric score
- [ ] Obviously broken outputs rank below plausible ones
- [ ] Scoring integrates with offset search outputs
