# Ticket 2.4 — Build Canon IXUS 310 HS Header Template Generator

**Epic:** 2 — Camera-Aware JPEG Reconstruction
**Complexity:** High

## Goal

Construct a valid JPEG header from a `CameraJpegProfile` for use in reconstruction.

## Why

Phase 2 needs a valid camera-specific wrapper that can be prepended to carved entropy data.

## Scope

In a module like `src/reconstruct/header_builder.rs`, implement logic to assemble:

1. SOI
2. APP0 and/or APP1 if needed
3. DQT
4. SOF0
5. DHT
6. DRI (if present)
7. SOS

The builder must:

- use Canon IXUS 310 HS profile values
- insert width and height into SOF0
- preserve component sampling structure
- emit a byte-perfect JPEG header ending at SOS

Do not include entropy data or EOI in this ticket.

## Deliverables

- Header builder function returning `Vec<u8>`
- Tests that validate header begins with `FF D8` and ends at SOS
- Tests for width/height injection

## Acceptance Criteria

- [ ] Builder emits a structurally valid JPEG header
- [ ] SOF0 dimensions are correctly inserted
- [ ] Output can be concatenated with entropy data and `FF D9` later
