# Ticket 3.2 -- Corruption Boundary Detection

**Epic:** 3 -- Entropy-Aware Scan
**Complexity:** Medium

## Goal

When encountering:

- Unexpected FF xx inside entropy
- Out-of-bounds
- Max size exceeded

Return:

```rust
EntropyResult {
    end_offset,
    reason: EntropyTerminationReason
}
```

## Definition of Done

- [ ] Clean corruption reason returned
- [ ] No panic on malformed input
