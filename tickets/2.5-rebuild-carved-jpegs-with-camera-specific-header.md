# Ticket 2.5 — Rebuild Carved JPEGs with Camera-Specific Header

**Epic:** 2 — Camera-Aware JPEG Reconstruction
**Complexity:** Medium

## Goal

Integrate the Canon IXUS 310 HS header builder into the reconstruction pipeline and generate rebuilt JPEG candidates from carved entropy streams.

## Why

This is the first full camera-aware recovery path and should improve colour correctness and general decode stability.

## Scope

Implement a reconstruction step that takes:

- inferred or known dimensions
- carved entropy stream
- Canon IXUS 310 HS profile

and outputs:

- header + entropy + EOI

Store outputs separately from raw carved files so Phase 1 and Phase 2 results can be compared.

## Deliverables

- JPEG rebuilder function
- Output naming convention for rebuilt files
- Comparison examples against baseline carved outputs

## Acceptance Criteria

- [ ] Rebuilt JPEGs decode in standard viewers
- [ ] Severe colour-shift cases can be tested against baseline
- [ ] Phase 1 and Phase 2 outputs are easy to compare
