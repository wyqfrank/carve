# Ticket 3.1 -- Implement Entropy Scan Engine

**Epic:** 3 -- Entropy-Aware Scan
**Complexity:** High

## Goal

In `entropy.rs`:

```rust
fn scan_entropy_stream(
    bytes: &[u8],
    start: usize,
    max_end: usize
) -> EntropyResult
```

Where:

- `start` = first byte after SOS segment
- Must:
  - Handle FF 00 byte stuffing
  - Allow FF D0..D7 restart markers
  - Detect FF D9 as EOI
  - Detect invalid marker in entropy

Most subtle part of Phase 1.1.

## Definition of Done

- [ ] No false EOI on stuffed bytes
- [ ] Restart markers allowed
- [ ] Proper termination on EOI
