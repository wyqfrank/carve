# Ticket 2.3 — Implement Camera JPEG Profile Model

**Epic:** 2 — Camera-Aware JPEG Reconstruction
**Complexity:** Medium

## Goal

Create a Rust representation of a reusable camera-specific JPEG reconstruction profile.

## Why

You need a structured way to store the Canon IXUS 310 HS header information required for rebuilding carved JPEGs.

## Scope

Add a module such as `src/reconstruct/camera_profile.rs` and define a type like:

```rust
pub struct CameraJpegProfile {
    pub model_name: String,
    pub dqt_segments: Vec<Vec<u8>>,
    pub dht_segments: Vec<Vec<u8>>,
    pub sof0_template: Sof0Template,
    pub dri: Option<u16>,
    pub sos_segment: Vec<u8>,
}
```

Also define any helper structs needed for:

- image precision
- component count
- component IDs
- sampling factors
- quant table selectors

Make sure the design allows width and height to be injected later for reconstructed files.

## Deliverables

- `CameraJpegProfile` struct
- Helper types for SOF0-related fields
- Constructor or loader for Canon IXUS 310 HS profile

## Acceptance Criteria

- [ ] Profile can represent all required Canon header fields
- [ ] Width and height are not hardcoded into the reusable profile
- [ ] Design is reusable for future camera models
