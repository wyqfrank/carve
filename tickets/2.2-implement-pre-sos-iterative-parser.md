# Ticket 2.2 -- Implement Pre-SOS Iterative Parser

**Epic:** 2 -- Pre-SOS Segment Parser
**Complexity:** High

## Goal

```rust
fn parse_until_sos(
    bytes: &[u8],
    start: usize,
    max_size: usize
) -> Result<PreSosResult, ParseError>
```

## Responsibilities

- Confirm SOI
- Iterate markers
- Parse each segment
- Stop at SOS
- Track:
  - segments parsed
  - has_dqt
  - has_dht
  - has_exif
  - SOF metadata
- Error on structural corruption

## Hard Parts

- Marker prefix detection
- Bounds checking
- Prevent infinite loops

## Definition of Done

- [ ] Successfully parses real camera JPEG
- [ ] Rejects random noise candidates
- [ ] Stops exactly at end of SOS segment
