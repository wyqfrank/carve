# Ticket 2.11.3 — Combine Decode-Based Scoring Function

**Epic:** 2.11 — Decode-Aware JPEG Validation & Scoring
**Complexity:** Medium

## Goal

Combine decode-based metrics into a single unified score.

## Scope

Implement scoring function:

```rust
score =
    0.4 * decode_success
  + 0.2 * colour_balance
  + 0.2 * pixel_entropy
  + 0.2 * (1 - artifact_penalty)
```

Notes:

- Clamp score to [0,1]
- If decode fails → score should be near 0

## Deliverables

- `score_image(decoded: DecodeResult) -> f32`

## Acceptance Criteria

- Produces meaningful ranking across candidates
- Visually correct images consistently rank higher
- Broken images rank lower
