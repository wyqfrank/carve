# Ticket 3.7 -- Implement Overlapping Candidate Suppression

**Epic:** 3 -- Entropy-Aware Scan
**Complexity:** Medium

## Goal

Suppress overlapping validated candidates so the same JPEG is not emitted multiple times.

## Problem

Multiple SOI markers may exist inside the same JPEG container, producing overlapping ranges.

## Responsibilities

Given:

```rust
Vec<Candidate>
```

Implement suppression:
- Sort by:
  - start ascending
  - end ascending
- Iterate in order
- Emit candidate only if:
  - `candidate.start >= last_emitted_end`
- Suppress:
  - nested candidates
  - partially overlapping candidates
  - duplicate ranges

### Edge Cases
- identical start/end -> emit one
- recovered vs truncated overlap -> recovered wins
- earlier valid candidate preferred by default

## Definition of Done

- [x] Overlapping candidates suppressed deterministically
- [x] Non-overlapping candidates still emitted
- [x] Duplicate nested JPEGs do not produce duplicate output
